# Axxon Sprint0 Suite — Repositorio

Skills de Sprint 0 de Axxon Consulting (`d365-requirements-analyst`, `bpc-analyser`) para
proyectos Dynamics 365 / Power Platform, empaquetadas como plugin de Claude Cowork.

Ver `plugins/axxon-sprint0-suite/README.md` para el detalle funcional de cada skill.

## Instalación

```
/plugin marketplace add <url-de-este-repo>
/plugin install axxon-sprint0-suite@axxon-sprint0-suite-marketplace
```
